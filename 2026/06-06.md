## ⚡ [效率信号] Lowfat：CLI 输出过滤器，砍掉 91.8% LLM token 成本

→ **事实**：Show HN 项目 [Lowfat](https://github.com/zdk/lowfat) 获 102 分 / 54 条评论。它是一个轻量 CLI 过滤器，在 CLI 输出到达 AI agent 之前过滤掉冗余内容。实测在 `git diff` 等场景下减少 91.8% token 消耗。单二进制文件、本地优先、无遥测。

🔑 **动作**：明天安装 lowfat 并集成到你的 AI coding workflow 中。先在 `git diff`、`git log`、`ls -la` 三个高频场景测试 token 节省效果。如果月 LLM 支出 >$50，这个工具 10 分钟就能回本。

🔮 **二阶**：
- 30 天：更多 CLI 过滤器涌现，形成 "AI agent 中间件" 品类
- 90 天：Cursor/Windsurf 等 AI IDE 内置类似功能，独立工具需差异化
- 180 天：token 压缩成为 AI 工具链标配，不压缩的 workflow 等于烧钱

⚠️ **反向检验**：如果 LLM token 价格继续大幅下降（过去 12 个月已降 90%+），过滤器的 ROI 会缩小。判断标准：当 Claude/GPT 的 token 单价降到 $0.01/1M 以下时，这类工具的必要性降低。

🔗 https://github.com/zdk/lowfat

## 🆕 [新发现] pg_durable：微软把 durable execution 塞进 PostgreSQL

→ **事实**：微软开源 [pg_durable](https://github.com/microsoft/pg_durable)（HN 281 分 / 72 评论），在 PostgreSQL 17/18 内实现长时间运行、容错的 SQL 函数。无需 Temporal、Inngest 等外部编排引擎，直接在数据库层完成 durable workflow。

🔑 **动作**：如果你的项目已有 PostgreSQL，评估 pg_durable 能否替代现有的 workflow 引擎（Temporal/Inngest/BullMQ）。特别适合：webhook 处理、多步事务、定时任务。先在非核心路径试用。

🔮 **二阶**：
- 30 天：PostgreSQL 生态出现基于 pg_durable 的模板和 starter kit
- 90 天：中小项目架构简化——数据库即 workflow 引擎，减少 1-2 个运维组件
- 180 天：Temporal 等独立 workflow 引擎面临 PostgreSQL 原生方案的直接竞争

⚠️ **反向检验**：如果 pg_durable 在高并发场景下性能不如独立引擎（PostgreSQL 单线程写入限制），或者团队不熟悉 PL/pgSQL，采用成本会高于收益。观察 90 天内的 production case study。

🔗 https://github.com/microsoft/pg_durable

## 💀 [死亡信号] Mantine-datatable 被投毒：npm 供应链再爆雷

→ **事实**：HN 56 分 / 23 评论。流行 React 组件库 mantine-datatable 的维护者账户被暂停，npm 包疑似被注入恶意代码。GitHub 讨论区确认了安全事件。这是继 event-stream、ua-parser-js 之后又一起高知名度 npm 供应链攻击。

🔑 **动作**：
1. 立即检查你的 `package-lock.json` 是否包含 `mantine-datatable` 或 `icflorescu` 相关包
2. 如果在用，锁定到攻击前的已知安全版本或寻找替代品
3. 启用 `npm audit signatures` 并在 CI 中加入供应链扫描（推荐 socket.dev）

🔮 **二阶**：
- 30 天：更多 npm 维护者账户被攻击，开源信任危机加剧
- 90 天：企业级项目加速转向 lockfile 审计 + SBOM（软件物料清单）强制化
- 180 天：npm 生态可能出现 "verified publisher" 付费认证机制

⚠️ **反向检验**：如果这只是孤立事件（维护者凭据泄露），不代表系统性危机。但 npm 供应链攻击频率在上升，这不是第一次也不会是最后一次。

## 底层逻辑：今日信号的共同主题

今天 5 条信号指向同一个结构性趋势：**AI 工具链正在从"能用"走向"好用"，同时安全成本在急剧上升。**

Lowfat 和 pg_durable 代表了效率优化的方向——当 AI 工具从尝鲜进入日常工作流，每一层的冗余成本都被放大。91.8% 的 token 节省不是炫技，而是因为当你的 AI agent 每天跑 100 次 git diff 时，未过滤的输出每月烧掉的钱够买一台服务器。pg_durable 则从架构层砍掉了中间件——如果 PostgreSQL 能直接跑 workflow，为什么还要运维 Temporal？
