## 🆕 [新发现] 950 个 Claude agent / 21 小时 / 2.1 亿 token 找出 ART 酶系统——"窄域可验证数据 × 并行 agent"成为发现的基本单位

→ **事实**：Anthropic 公布其生命科学研究组（2026 春季成立、自建实验室）的早期成果：只给一句初始 prompt，约 **950 个 Claude agent 并行跑 21 小时、消耗 2.1 亿 token**，从海量 DNA 序列库里收集 20 万条逆转录酶（RT），筛出 3,500 个候选系统，再收敛成 20 份人类可读报告，其中一个 agent 在原始序列里肉眼发现"串联重复阵列"，最终确认一个此前未被描述、存在于噬菌体中的酶系统，命名 **ART（array-associated reverse transcriptase）**——结构与 CRISPR 的重复阵列同构，已出预印本并在自家实验室完成首批验证（HN 439 分 / 489 评论）。CRISPR 先驱、MIT/Broad 的 Feng Zhang 评价这是"AI agent 参与生物发现的令人兴奋的例子，逆转录酶旁的 RNA 重复阵列确实值得进一步研究"。The Verge 的标题聚焦"近 1000 个 Claude agent、21 小时、2.1 亿 token"；HN 高赞评论则当场质疑叙事："我们仍然处在 AI + 人类的世界，为什么标题不写'一支由 Anthropic 支持的研究团队用 Claude 发现了……'"。

🔑 **动作**：（1）**今天就把这个模式搬到你自己的窄域**：选一个"数据在我手里、对错可被客观验证"的语料（你自己的客服工单、日志、合同、判决书、招标文件、竞品变更记录），起 20–50 个并行 agent 跑"找出异常 / 找出重复结构"这一条指令，产出物是**带坐标的候选清单 + 人类可读报告**，不是综述文章；（2）把"21 小时 × 950 agent"换算成钱：2.1 亿 token 按当前"够用档"价格是几十到几百美元量级——**一次完整发现扫描的成本已经低于你一天的人力成本**，这意味着这件事的门槛不是钱而是你敢不敢先定义"什么算异常"；（3）发布节奏学它：先出预印本/公开报告占住关键词，再补实验——对一人公司，这就是"先发数据、后卖服务"的次序。

🔮 **二阶**：
- 30 天：跟在后面的会是"某领域 agent 扫描发现 X 篇"的批量产出，垂直领域的"发现权"争夺开始，谁先公开谁占位
- 90 天：出现"扫描即服务"的供应商——你付费，他把你行业的公开语料扫一遍给你候选清单
- 180 天：科研与商业情报的分界消失，"我读完了所有资料"这句话被"我扫完了所有资料并列出 20 个异常"替代；不会用并行 agent 扫语料的分析师产出会被按 token 计价的对手碾压

⚠️ **反向检验**：如果 ART 的功能最终被证明只是已知系统的变体（Anthropic 自己承认"我们尚不知道它的功能"），那这条信号的价值不在生物发现，而在**方法**——判断方法是否可复制只需看一件事：非 Anthropic 团队能否用同样的并行扫描模式在自己的语料上产出可验证结果。另一个证伪点：如果 950 个 agent 的真实贡献只是"穷举检索 + 关键词匹配"，那它不构成新能力，只构成更快地做一次暴力搜索（可测：把同样的数据给一个 grep + LLM 判定的两阶段流水线，看能否得到同样候选）。

## 💰 [收入信号] Jev 把输入价打到 $42/十亿 token、输出免费——计价单位从"token"迁到"决策"，按产出定价的窗口正在打开

→ **事实**：TypeSafe AI 发布 System One + **Jev**：它**不生成文本**，只在一个预先给定的选项集合上输出 0–100 的概率（例如"这条 shell 命令是否违反系统提示 / 是否会造成破坏性变更"）。定价表是本次发布真正的主角：输入 **$0.042 / 百万 token（$42 / 十亿）**，**输出免费（"too cheap to meter"）**，对照现有 LLM 的 $0.20–$10 / 百万输入、输出约为输入的 5 倍；$1 可买 2,380 万 input token，官方换算约"读五本书 3 美分"。同一周 jyn.dev 的《Tokens too cheap to meter》在 HN 拿到 222 分 / 176 评论，论点是从 **"每 token 便宜"到"每任务便宜"**：前沿模型的单 token 价并不总在降，但单任务成本在数量级下降，且 3–6 年内可能在本机跑出当前前沿质量。而真正的反面证据来自厂商自己：Google 在 Gemini 3.8 Flash 的发布说明里写"性能提升来自一个核心设计选择：3.8 Flash 更努力"——在复杂任务上执行更多推理步、更多轮工具调用、消耗更多 token；分析师直接点评"token 定价已经不足以衡量推理经济学"。HN 上另一条高赞反论：这些价格是"以创纪录速度亏损的公司"报出来的，Stein's Law 说不可持续的东西终将停下。

🔑 **动作**：（1）**今天把你的成本口径从"每千 token"改成"每任务 / 每决策"**：挑三个最贵的工作流，记下每次完整跑通的 token 账单和产出数量，算出单产出成本——这是你唯一能用来定价的数字，别人的单价表与你无关；（2）把所有"是/否/打分/路由/质量门禁"环节从生成模型换到决策模型：这类环节你付的是文本价钱、用的是分类能力，成本可以降到原来的百分之一到千分之一量级（Jev 已在 B.AI API 上线，先用一个非核心门禁做 A/B）；（3）定价页按结果计价（per document / per run / per decision），并明说"输出不额外计费"——当上游把 token 变成基础设施，终端客户对标的是"这件事值多少钱"。

🔮 **二阶**：
- 30 天：出现一批"输出免费、按判定次数收费"的中间层产品，把 LLM 当 CPU 按次计费
- 90 天：agent 产品的定价模板从"$X/月含 N 次"改写为"按产出的可用件数"，毛利结构重新洗牌
- 180 天："按 token 计费"变成只有 API 转售商才用的模式，终端客户用"每次决策多少钱"比较所有供应商

⚠️ **反向检验**：Jev 输出的是**概率而非答案**，如果你的领域没有可标注的判据，你无法验证它的校准，省下的钱会以返工形式还回去——先在一个有 ground truth 的环节验证 calibration 再推广。第二重风险：这个价位来自仍在补贴推理的厂商，一旦资本开支压力兑现、价格回升，按"token 免费"假设设计的产品会瞬间失去毛利；判断指标是上游是否披露推理毛利或开始限流。

## ⚡ [效率信号] Stripe 的内部知识 agent"Kai"：上线两周覆盖全公司、83% 周活、1,000+ 内部 skills，且与产品侧共用同一套 harness 与沙箱

## 底层逻辑：今日信号的共同主题

**第一层：智能的单价正在失去解释力，判断的定义权在升值。** 今天最锋利的三条线其实是同一件事：Jev 把输入价压到 $42/十亿、输出免费，Gemini 3.8 Flash 官方承认"更努力所以更费 token"，而 HN 上讨论的是"每任务成本"而非"每 token 价格"。当调用智能便宜到不值得计量，唯一还能定价的东西就变成了"什么算正确"——Anthropic 的 ART 之所以值钱，不是因为 2.1 亿 token 值钱，而是因为有人先定义了"什么算异常"，950 个 agent 才有意义。所以今天最贵的能力，是**把一个领域的问题形式化成可被机器穷举、且结论能被验证的判据**。

**第二层：发现与产出正在并行化，交付单位从"文章/岗位"变成"可验证的候选清单"。** 950 个 agent 交出的不是综述，是 20 份带证据的候选报告；Stripe 的 Kai 交出的不是聊天记录，是可对外分享的 artifacts；Unlisted 交出的不是观点，是 607,050 个岗位的存活曲线。三者都在做同一件事：把"人读完全部资料"换成"机器扫完全部资料、只把异常端到人面前"。相反方向的失败案例也在同一天出现——Claude Code 的指令文件因为一个远端开关被静默跳过、WordPress 式的地基问题、28% 的岗位挂单无人处理——**验证成本没有被消灭，只是被推给了不设防的那一环**。

**第三层：分发与用工的旧信道同时在失效，公开产物成为唯一可信凭证。** 雇主官网 28.3% 的岗位挂满 90 天、4.2% 下架即回炉，说明"挂出来"不再等于"要人"；Stripe 让非工程岗也用上 harness，说明"技能"正在从岗位描述迁移进 skills 目录。两者合起来给出同一句结论：**在旧信道里刷存在感的边际收益在归零，在新信道里留下可被机器读取、可被验证的产物（skill、报告、数据集、公开测试题）的边际收益在暴涨**。今天的行动顺序：先用 canary 确认你的指令真的被读到、把你的 SOP 拆成 skills，再用几十美元级别的一次并行扫描，在只有你拥有的语料上抢一个"我先发现的"的位置。
