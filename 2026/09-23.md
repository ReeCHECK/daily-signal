## ⚡ [效率信号] GPT-6 Sol/Luna 降价 50% + Claude Opus 5.5 缓存读价降 60%——agent 成本的主战场从 token 单价转到缓存

→ **事实**：9 月 22 日同一天两家同时降价。OpenAI 发布 GPT-6 Sol / Luna，API 价格比 GPT-5.6 促销价再降 50%：AutomationBench 上 Sol（xhigh）超过 Claude Opus 5（max），单任务成本只有它的 9%；Luna 比前代能力 +5.4pp、单任务成本低 58%；DeepSWE v1.1 上 Sol（max）68.8%，逼近 Fable 5（xhigh）的 69.9%，但单任务成本低约 80%；Luna（max）66.6%，单任务成本比 Opus 5 低 93%、比 Fable 5 低 96%（HN 1084 分 / 565 评论）。Anthropic 同步发 Opus 5.5：$4/$20 每百万 token（比 Opus 5 低 20%），**缓存读价 $0.20/M（低 60%）**，输出速度 +30%，官方称默认设置下典型负载成本低 40%，早期测试者用它在一天内完成 68 万行代码迁移，39/40 次成功压低整个 web app 的页面加载时间（HN 1120 分 / 774 评论，两帖同时霸榜）。OpenAI 还顺手披露内部账：研究员日均 token 消耗按 API 价折算，**中位数超过 $600、P90 超过 $7,000**。前一天的背景是 AMD 放出 Zebra-HyLo：14 个 checkpoint 把 KV cache 砍掉 92–98%，8×MI300X 上在 vLLM 里跑 2M 上下文，只需约 10B token 后训练。

🔑 **动作**：（1）今天就把你最贵的那个工作流（长上下文 + 多轮 + 缓存命中率高）同时挂到 `gpt-6-sol` 和 `claude-opus-5-5` 上，用你自己的 eval 打分——单任务成本差 9%~20% 意味着你的毛利结构可能被直接重写；（2）改架构去赚"缓存读价"的钱：Opus 5.5 缓存读价是输入价的 5%，任何把上下文做成「稳定前缀 + 变化尾部」的设计现在直接省钱——今天就按前缀稳定性把你最长的那个 prompt 重排一遍；（3）停止"省 token"级别的微优化，成本地板上移的速度快过你的优化速度，省下来的钱投到数据壁垒与分发上。

🔮 **二阶**：
- 30 天：Sonnet 5.5 / Haiku 5.5 跟上，中端价位再被清一遍，"够用档"价格跌破认知下限
- 90 天：以"模型调用量"为核心的套壳产品毛利被压平，agent 产品被迫转向按产出/结果定价
- 180 天：上下文与缓存工程成为唯一的成本护城河，"用哪家模型"退化成配置文件里的一行

⚠️ **反向检验**：如果 Sol/Luna 的性价比全是在自家 AutomationBench / Agents' Last Exam 上堆出来的、在你真实的长尾任务上掉分，那 50% 降价买回来的是返工时间——唯一可行的判断方法是跑你自己的 eval，别信官方 benchmark。另一个证伪点：Opus 5.5 带 `preserved thinking` 防蒸馏限制（8/31 之后创建的 API 账户生效），如果你的调用方式需要改写历史上下文，升级后可能直接被拒——先在非生产 key 上跑通再切。

## 💰 [收入信号] Snorkel AI $350M E 轮 / $3.5B 估值、ARR 一年从 $20M 冲到 $375M——"专家判断的结构化封装"是当下最贵的商品

→ **事实**：TechCrunch 报道 Snorkel AI 完成 $350M E 轮，估值 $3.5B（Insight Partners 与 S32 领投，Addition / Lightspeed / Greylock / GV / Wells Fargo 跟投），估值是 17 个月前 D 轮 $1.3B 的近三倍；年化收入从 $20M 涨到 $375M（12 个月 18 倍）。它去年整体从"标注软件"转向 Data-as-a-Service：不卖工具，卖**专家级 agentic 任务、可执行环境和评分 rubric**。Snorkel 官方对这批商品的描述是：即使对最有资格的专家，构建一条也要花几小时到几天——"把它们设计好本身是研究工作，质量与复杂度决定价值"。同一天的另一条线：Alphabet 的 Intrinsic 在 ROSCon 2026 开源了整条机器人栈。

🔑 **动作**：（1）如果你在某个垂直领域有真实判断力（法律、财务、医疗、工业、某类工程评审），今天就把它结构化成"任务 + 环境 + rubric"三件套——这是正在以 $375M 年化规模被采购的东西，而不是又一个 API wrapper；（2）别去做"帮人标注数据"的劳务，去做"定义什么算正确答案"的定价方，rubric 的定价权来自你的判断能被当作校准标准；（3）一人公司的最小可行版本：选 3 个你每天都在做的专业判断，写成 10 条可验证 rubric + 20 个边界 case，先公开（GitHub / 知乎 / 小红书）当样品，等着被实验室或企业拉进供应商池。

🔮 **二阶**：
- 30 天：更多"专家 environment"供应商出现，数据供应链成为 AI 的隐形上游
- 90 天：领域专家的定价从"小时劳务"变成"按环境 / 按 rubric 授权"，出现可复制的报价模板
- 180 天：模型能力趋同后，"评估数据的稀缺性"成为真正的瓶颈——掌握 rubric 定义权的人比掌握模型的人更值钱

⚠️ **反向检验**：如果 18 倍增长主要来自少数前沿实验室的一次性外包采购而非持续续约，那就是训练周期的脉冲、不是可持续市场。判断指标：未来两个季度是否披露留存/续约率，以及各实验室自建数据团队的规模变化。

## 💀 [死亡信号] CLOSEDQUORUM：首个完全自主的 AI C2 植入（四家模型投票、无人类操作员）；同日 WordPress 核心未授权路径穿越条件 RCE

→ **事实**：Cisco Talos 发布 CAIRN（开源 AI 集成恶意软件追踪框架）并披露首个样本 CLOSEDQUORUM：16.4MB 的 64 位 Windows 植入体（Go 编写），**把 LLM 供应商当作 C2 通道**——启动时采集主机名/架构/CPU 数/Windows 版本/管理员状态注入 prompt，依次问 DeepSeek、Qwen、Mistral、Gemini"下一步做什么"，按结构化 JSON 的 decision 字段投票执行（平票按提交顺序，DeepSeek 优先），目标是窃取凭据与加密货币钱包，外传走 Discord webhook，随机 5–15 分钟唤醒一次；没有操作员、没有 C2 服务器、没有人类介入通道（二进制里的系统提示词只有 9 个词："You are an advanced malware strategist. Provide ONLY executable decisions."）。Talos 明确两点：**未确认野外部署**，公开分发版是惰性样本（占位 API key + 假 webhook）。Talos 的纵向观察更重要：从"LLM 作为可选功能"到"完全自主的多模型共识编排"，这个演进在**一个自然年内**完成。同一天，WordPress 发布 7.1.2，修复未授权 page-template 解析路径穿越导致的条件 RCE（GHSA-7hp8-65ch-5whp，CVE-2026-87902，Critical，回补到 4.7；HN 147 分 / 77 评论），这是继本月 wp2shell 链（CVE-2026-63030，9.8 + CVE-2026-60137，9.1，已在野外被利用）之后同一核心代码库的第二个未授权入口。

🔑 **动作**：（1）今天逐个站点把 WordPress 升到 7.1.2，并用 `wp core version` 亲自验证（官方会强制推送修复，但"推送过"不等于"已生效"，而攻击者已在野外利用同一代码库的另一条链）；（2）给你的自建 agent 拆掉至少一个"无人值守 + 有写权限 + 能任意出网"的组合：出网白名单、写操作需签名确认、定时任务默认只读——三者留其一才安全；（3）防守侧直接抄 CAIRN 的元数据思路：一个进程在短时间内同时联系多个模型供应商域名 + 发送携带主机上下文的结构化 prompt + 触摸 LSASS 或注入挂起进程 = 告警组合，不用看二进制。

🔮 **二阶**：
- 30 天：AI 供应链安全（CAIRN / Plugin4Shell 一类）成为独立赛道，企业开始强制 agent 与插件清单
- 90 天：攻击链更多环节被外包给模型，"人不在环"的攻击频率上升，防守方被迫从 IOC 转向行为组合检测
- 180 天：agent 运行时的权限沙箱与审计（谁能读、谁能写、谁联网）成为默认采购条件，像今天的 SSO 一样

⚠️ **反向检验**：如果 CLOSEDQUORUM 始终拿不出野外部署证据（目前分发样本就是惰性占位），那它更像"能力演示"而非活跃威胁——但"概念已被公开、且一年内就从可选功能演进到完全自主编排"这一点已经成立。判断指标：未来 90 天是否出现携带真实 key 的变体或同类样本。

## 底层逻辑：今日信号的共同主题

**第一层：智能在贬值，判断力在升值。** 同一天两家前沿实验室把价格再砍一半、缓存读价砍 60%，加上 AMD 把 KV cache 压掉 92–98%，"调用智能"的单位成本正加速趋近于零。而同期最贵的商品变成了 Snorkel 卖的那种东西：专家的判断被结构化成任务、环境和 rubric——它的 ARR 一年涨 18 倍这个数字，比任何模型发布都更清楚地说明了钱在往哪里流。当智能是廉价商品，定价权就转移到"定义什么是对的"。

**第二层：分发单元在换代，从 SaaS 到 skills。** GitHub 本周涨得最猛的是一批 SKILL.md 与 agent harness，而不是应用：265k 星的 harness、98k 星的工程技能、垂直到 LinkedIn 内容写作的技能包。技能的交付形态（纯文本、跨平台、可被 agent 自动安装）让它同时是产品、渠道和营销素材——大厂把能力做成技能目录，个人把判断做成技能分发，而且这个窗口目前还没有排名壁垒。同时要注意"确定性管线 + LLM"的混合架构（alibaba/open-code-review 一周 +12,590 星）说明市场已经在给"可控性"投票，而不是给"全自动"投票。

**第三层：自动化在膨胀，验证成本却在转移给最后接住后果的人。** CLOSEDQUORUM 把 C2 外包给模型投票、WordPress 核心被未授权打穿、Meta 用人工冒充自动化，加上 HN 上 351 分的"五角大楼承认过度依赖 AI 导致了伊朗学校被炸"——四件事指向同一个结构性问题：当自动化成为默认，验证与信任的成本不会被消灭，只会被推给不用承担的最后一环。所以今天的动作优先级是：先堵住"无人值守 + 写权限 + 任意出网"的组合，再吃降价红利把长上下文任务解锁，最后把只有你能做的判断封装成别人必须买的东西。
